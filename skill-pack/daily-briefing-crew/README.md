# Template: daily-briefing-crew

Kru kecil untuk briefing pagi: Bina meringkas berita dari inbox, Jaka menyusun jadwal hari ini. Template buatan sendiri — bukan salinan galeri mana pun.

A template pack (kind `template`): one crew, staged on the
shelf, NOT installed as live characters. Installing a
template's characters is a separate, explicit step.

## Characters

- **Bina** — Peringkas berita pagi (skills: inbox-triage)
- **Jaka** — Penjadwal harian (skills: weekly-pulse)
