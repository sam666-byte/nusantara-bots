# Facilitate an Agent Meeting Room

You run a meeting room: several agents debate a disputed decision under a hard message budget, and the room's owner makes the final call. The room is for escalation, not routine work — daily business runs through normal channels, and a room is opened only when a decision is genuinely contested.

## Set up the room

- Name a moderator and one participant per topic before opening. Five to six participants is enough for a real debate.

- Write the agenda and a hard message budget before the first turn. Thirty to forty messages fits a full round.

- Open with the agenda only. Do not research, read or prepare in the opening turn.

## Pass the floor with tool handoffs

- End every turn by calling the platform's handoff tool with the next speaker's name and the order after them. Text-only invitations do not wake the next participant.

- Chain handoffs speaker to speaker instead of letting the moderator hold the floor between participants.

- Reopen a dead floor by having the moderator call the handoff tool directly with the next speaker.

- Platform handoff tools differ, so verify the exact handoff call on the platform you use before opening.

## Run the four phases

- Start with the moderator stating the agenda, the budget and the stop rule, then handing off to the first analyst.

- Give each participant one analysis round, then hand off to the next. Run the analysis round only once.

- Force the debate next. Each participant attacks the weakest claim from an earlier analysis with evidence, and the attacked claim's owner defends or concedes.

- Close by having the moderator hand the decision to the room's owner with disputed points still listed. Execute nothing before the owner approves.

## Enforce the stop rules

- Ban empty confirmations and empty tags between participants. A message with no claim and no handoff only burns budget.

- Stop the room on the owner's stop word. Give one in-flight status report, then stand down completely.

- Close the room when the budget runs out. The moderator writes a summary and hands it to the owner. Do not extend the budget mid-room.

## Close with a useful summary

Every moderator report to the owner closes with two things:

1. The points still disputed, with the evidence on each side.
2. A recommendation: hold a further meeting, or the evidence is sufficient and no meeting is needed.

Record the killed claims with their evidence in the final summary. The debate's value is the claims it killed, not the ones it confirmed.

## Alternatives for better results

- Reserve the room for escalation and run daily work through normal channels. A room is for disputed decisions, not routine status.

- Let the room's owner watch the room directly. An owner who sees the debate trusts the outcome.

- If the room needs tools or data the participants lack, set up the platform's available connectors before opening.

- This method was proven in a single six-participant room run.
